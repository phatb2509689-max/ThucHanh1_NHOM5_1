# THỰC HÀNH ỨNG DỤNG AI TRONG HỌC TẬP VÀ KỸ THUẬT SỐ

## Mục tiêu
Sử dụng các công cụ AI để hỗ trợ cấu hình phần cứng, cài đặt phần mềm, khắc phục sự cố kỹ thuật cơ bản và tạo nội dung học tập số trên hệ điều hành Windows 11, đáp ứng các chuẩn CLO11, CLO12, CLO13 và CLO14.

---

## PHẦN 1: CẤU HÌNH PHẦN CỨNG VÀ PHẦN MỀM VỚI HỖ TRỢ AI (CLO13)

### Nhiệm vụ 1.1: Tìm hiểu cấu hình phần cứng
**Các bước thực hiện:**
1. Sử dụng Google Bard hoặc Grok để tìm hiểu thông số CPU, RAM, ổ cứng trên Windows 11.
2. Mở Task Manager để kiểm tra cấu hình phần cứng thực tế của máy.
3. Ghi lại thông tin CPU, dung lượng RAM và loại ổ cứng.
4. Chụp ảnh màn hình kết quả kiểm tra.

**Sản phẩm:**  
- File mô tả cấu hình phần cứng  
- Ảnh chụp màn hình Task Manager  

---

### Nhiệm vụ 1.2: Cấu hình phần mềm cơ bản
**Các bước thực hiện:**
1. Sử dụng AI để tìm hướng dẫn cài đặt Notepad++ trên Windows 11.
2. Tải và cài đặt Notepad++ từ trang chính thức.
3. Tạo file Python đơn giản (`hello.py`) và nhập mã nguồn.
4. Lưu file và chụp ảnh màn hình Notepad++.

**Sản phẩm:**  
- File Python  
- Ảnh chụp màn hình Notepad++  

---

## PHẦN 2: GIẢI QUYẾT SỰ CỐ KỸ THUẬT ĐƠN GIẢN VỚI AI (CLO11)

### Nhiệm vụ 2.1: Xử lý sự cố kết nối Wi-Fi
**Các bước thực hiện:**
1. Sử dụng AI để tìm cách khắc phục lỗi Wi-Fi không kết nối trên Windows 11.
2. Thực hiện các giải pháp được đề xuất (kiểm tra driver, chạy lệnh `ipconfig`).
3. Kiểm tra lại trạng thái kết nối mạng.
4. Chụp ảnh màn hình kết quả.

**Sản phẩm:**  
- Báo cáo ngắn mô tả quá trình khắc phục  
- Ảnh chụp màn hình trạng thái Wi-Fi  

---

### Nhiệm vụ 2.2: Xử lý lỗi phần mềm cơ bản
**Các bước thực hiện:**
1. Sử dụng AI để tìm giải pháp khi Notepad++ không mở được file Python lớn.
2. Áp dụng giải pháp phù hợp (tối ưu cấu hình hoặc chuyển sang VS Code).
3. Thử mở file Python dung lượng lớn (>1MB).
4. Chụp ảnh màn hình kết quả.

**Sản phẩm:**  
- Báo cáo ngắn mô tả lỗi và giải pháp  
- Ảnh chụp màn hình kết quả  

---

## PHẦN 3: ỨNG DỤNG AI TRONG HỌC TẬP VÀ ĐẠO ĐỨC SỐ (CLO12, CLO14)

### Nhiệm vụ 3.1: Tạo nội dung học tập với Canva AI
**Các bước thực hiện:**
1. Sử dụng Canva AI để tạo infographic về ứng dụng AI trong công nghệ thông tin.
2. 2. Chỉnh sửa nội dung và hình ảnh từ nguồn miễn phí.
3. Xuất infographic dưới dạng file PNG.
4. Ghi rõ nội dung được tạo với sự hỗ trợ của AI.

**Sản phẩm:**  
- File infographic PNG  

---

### Nhiệm vụ 3.2: Đánh giá đạo đức khi sử dụng AI
**Các bước thực hiện:**
1. Nghiên cứu DigComp 2.2 hoặc tài liệu về đạo đức số.
2. Viết đoạn văn 100–150 từ về việc sử dụng Canva AI minh bạch và có trách nhiệm.
3. Lưu file văn bản và đăng tải lên GitHub cùng infographic.

**Sản phẩm:**  
- File văn bản đánh giá đạo đức sử dụng AI
